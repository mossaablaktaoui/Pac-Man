================================================================================
                    PAC-MAN: GHOSTS! MORE GHOSTS!
                     Standalone Release Instructions
================================================================================

1. QUICK START
--------------------------------------------------------------------------------
To launch the game on Linux, open a terminal in this directory and execute:

    ./pac-man config.json

    or 

    ./run.sh

Make sure the executable has execution permissions:
    chmod +x pac-man


2. CONTROLS & HOTKEYS
--------------------------------------------------------------------------------
Movement:
  - Arrow Keys (Up, Down, Left, Right) or WASD
  - Buffered turning: turns occur automatically at the next valid corridor opening.

Game Navigation:
  - P   : Pause / Resume gameplay (with blurred background modal)
  - R   : Restart / Replay the current level
  - Q   : Quit to Main Menu
  - ESC : Cleanly exit the game

Developer Debug Cheats:
  - K   : Skip Level - Instantly clear remaining pellets and advance level
  - L   : Speed Boost - Doubles Pac-Man's movement speed (0.10s interval)
  - H   : Unlimited Lives - Grants complete invulnerability against ghosts
  - J   : Freeze Ghosts - Freezes all ghost AI updates and navigation in place


3. CONFIGURATION (config.json)
--------------------------------------------------------------------------------
The game expects a JSON configuration file as its first CLI argument.
Lines starting with '#' are treated as comments and ignored.

Supported parameters:
  - highscore_filename       : Path to persistent highscore file (default: "highscores.json")
  - lives                    : Starting lives (default: 3, integer >= 0)
  - pacgum                   : Number of pellets in maze (default: 42, integer >= 4)
  - points_per_pacgum        : Score for eating a regular pellet (default: 120)
  - points_per_super_pacgum  : Score for eating a power pellet (default: 50)
  - points_per_ghost         : Base score awarded for eating a ghost (default: 200)
  - seed                     : Seed for initial level maze generator (default: 42)
  - level_max_time           : Time limit per level in seconds (default: 120)


4. HIGHSCORES & SAVING
--------------------------------------------------------------------------------
Top scores are persisted automatically to the file configured by
'highscore_filename' (by default 'highscores.json') in the local directory.
Player names support up to 10 alphanumeric characters.


5. GAMEPLAY & OBJECTIVES
--------------------------------------------------------------------------------
- Navigate the procedural 15x15 maze generated by the 42 A-Maze-ing algorithm.
- Eat all pellets and Super-pacgums to clear each level (10 total levels).
- Devour energized blue ghosts when Super-pacgums are active.
- Watch out for 4 distinct ghost AI behaviors:
    * Blinky (Red)   : Direct BFS shortest-path hunter
    * Pinky (Pink)   : Wandering explorer
    * Inky (Cyan)    : Interceptor projecting 5 tiles ahead
    * Clyde (Orange) : Take a random algorithm from the previous
